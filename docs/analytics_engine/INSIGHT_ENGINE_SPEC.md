# Explainable Natural Language Insight Specification

## 1. Insight Schema
Every insight provides a 5-step explainable breakdown:
1. **Natural Language Statement**: What happened ("Student mastery has increased by 18% over the last 14 days.")
2. **Why It Happened**: Diagnostic & activity root cause
3. **Emerging Trend**: Observed trajectory
4. **Action to Take**: Recommended next step
5. **Expected Improvement**: Estimated mastery delta
