# Navigation & GoRouter Specification

## 1. Registered Student Routes
- `/student-home-dashboard`: Primary home screen
- `/session-launcher`: Practice mode configuration
- `/question-player`: Question solving interface
- `/reflection`: Self-reflection prompt
- `/interactive-knowledge-map`: Knowledge DAG visualizer
- `/student-progress-dashboard`: Mastery & velocity dashboard
- `/student-goals`: Goal manager
- `/notifications`: Reminder center
- `/student-profile`: Profile & preferences
- `/app-settings`: Offline sync & theme settings
