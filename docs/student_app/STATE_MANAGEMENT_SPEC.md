# Riverpod State Management Specification

## 1. Provider Architecture
- `studentDashboardProvider`: Manages dashboard loading, streak, and motivational insights.
- `learningSessionProvider`: Manages session configuration & modes.
- `questionPlayerProvider`: Manages current question, timer, hints, and bookmarks.
- `reflectionProvider`: Manages student reflection input.
- `knowledgeMapProvider`: Manages DAG node selections.
- `progressProvider`: Manages overall mastery and velocity data.
