# BACKTRACE Learning Plan Generation Specification

## 1. Plan Types & Generation
- **Today's Plan**: Daily 45-minute structured plan containing 3 prioritized tasks (Resource review, targeted practice, spaced revision).
- **Weekly Plan**: 5-day roadmap outlining target concept mastery progression.
- **Recovery Plan**: Triggered on concept regression or misconception diagnosis.
- **Fast Recovery Plan**: Accelerated remediation sequence targeting prerequisite gaps.
